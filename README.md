## `> proyectos_destacados`

### 🍀 LuckyStore — Sistema de gestión para comercios

Sistema web multiempresa y marca blanca para comercios con una o varias sucursales: cada negocio lo ve con su propio nombre y logo.

- **Punto de venta:** búsqueda rápida de productos con foto, cálculo automático del total, descuentos, cobro con varios medios de pago y Plan Canje.
- **Stock por sucursal y por vendedor**, con colores y variantes, envíos entre sucursales e historial de movimientos.
- **Caja** con apertura y cierre, **clientes**, **proveedores**, **compras** e **insumos**.
- **Empleados** con roles y permisos, comisiones, pagos y objetivos de venta.
- **Dashboards y reportes** por rol, comprobantes imprimibles y exportación a PDF.

`Python` `Flask` `MySQL` `JavaScript` `HTML` `CSS`
